# AI Study Assistant

## Overview
AI Study Assistant is a full-stack web application that helps students transform study notes into summaries, flashcards, and quiz questions using Artificial Intelligence.

## Features
- AI-generated summaries
- Flashcards generation
- Quiz question generation
- Modern responsive UI
- Full-stack architecture using React and Flask
- Hugging Face AI integration

## Technologies Used

### Frontend
- React
- Vite
- CSS

### Backend
- Python
- Flask
- Flask-CORS
- Hugging Face API

### Tools
- Git
- GitHub
- VS Code

## Installation

### Backend Setup

```bash
cd backend
source venv/Scripts/activate
pip install -r requirements.txt
python app.py
```

## Frontend Setup
cd frontend
npm install
npm run dev
Environment Variables

## Create a .env file inside backend/:

HF_API_KEY=your_huggingface_api_key
Deployment
Frontend deployed with Vercel
Backend deployed with Render
